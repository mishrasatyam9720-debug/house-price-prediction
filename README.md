# House Price Prediction

A Machine Learning project that predicts house prices using various features such as area, location, number of rooms, and other property-related attributes.

## Model Used
- XGBoost Regressor

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- XGBoost

## Features
- Data preprocessing and cleaning
- Feature engineering
- Model training using XGBoost
- Model evaluation using regression metrics
- House price prediction
